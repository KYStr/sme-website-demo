# 下一輪 3D 場景修改需求

原排定於 2026-10-31 15:24（台灣時間）開始。工作已執行；實作、測試、截圖、獨立評分與未達標項目見 [`verification.md`](verification.md)。本文保留原始需求作為對照。

## 目標

1. **停站物件要能近看。** 六站鏡頭停穩後，主要物件須有足夠的形體、結構和材質細節。優先改善 CNC 加工機、成品架及零件盒、三次元量測機、出貨棧板與捲門。比例、擺位與工廠用途應合理，避免畫面看起來只是簡單方塊。保持虛構品牌與示意資料的聲明。
2. **恢復開門進廠的動作。** 從廠外捲到進廠時，鐵捲門應可見地升起，鏡頭在門口開出安全通道後連續前進，不能瞬間跳過開門，也不能穿過關閉的門。滾輪一次定位一站的操作仍要可靠。檢查目前捲動進度直接跳站、而門用原始進度驅動，是否使動畫被略過；讓門與鏡頭使用一致的視覺進度或等效的協調方式。
3. **照明明顯變亮。** 廠房內的加工區、成品架、量測室與出貨區都應能辨認機台輪廓、工作表面與空間分隔。亮度提高後仍要保留材質層次、局部燈光和文字對比，避免過曝或只把整個畫面洗白。
4. **捲動與文字保持穩定。** 不需要額外滾一下才離開兩站之間；任何時刻不能停在兩張重疊文案上。反向捲動、站點按鈕、手機觸控與減少動態效果模式也要正常。

## 驗收與評分

- 在 1440×900 與 360×800 實際看六站停留畫面及 00→01 開門過程，更新截圖／必要的短錄影。
- 執行 `npm run build`、`npm run lint`、`npx playwright test --workers=1`，並對開門與停站行為補上有意義的自動驗證。
- 請獨立檢視者分別評分：**工廠空間真實感、停站物件細節、照明與可讀性、鏡頭／開門動作、捲動與文字互動、桌面與手機構圖、效能與穩定性**。每項以 **9/10 以上**為完成目標，附上可核對的具體依據；未達標先修正再複評，不可為了過關而灌分。
