# 六站參訪動線與視線

鏡頭沿中央走道前進，停站時交替看左右兩側的工作區。走道內的鏡頭不穿過機台、成品架或量測室隔板；出貨站停在量測室通往出貨區的開放門口，向內看打包作業。這是虛構示範廠的參訪路線。

| 站 | 位置與停下來看的主體 | 停站動作 |
| --- | --- | --- |
| 00 廠外 | 外牆、招牌與入口鐵捲門；先交代廠房全貌。 | 無 |
| 01 進廠 | 門升起，鏡頭沿中央走道進入；兩側加工位與前方隔間建立空間關係。 | 入口門連續升起 |
| 02 加工區 | 看右側 CNC 加工中心的工作台、夾具、刀軸與控制屏；左側車床是另一個加工位。 | 刀軸低速進給、車床卡盤轉動 |
| 03 樣品架 | 轉向左側靜態架，近看軸心、法蘭、齒輪、治具板與標籤料盒。這是示意樣品展示，並非待檢的量產批次。 | 無 |
| 04 量測室 | 轉回右側，看有支撐座的花崗石平台、橋式量測機、探針與示意零件。 | 橋架滑座與探針緩慢移動 |
| 05 出貨區 | 從開啟的隔間門口看棧板上的裝箱品、掃碼檢核台、手動拖板車及後方出貨門。 | 固定設備維持靜止 |

物件的工序是加工、量測、裝箱出貨；樣品架是參訪時介紹品項的展示區。桌面與手機使用同一條走道，手機另調停站視線，讓主體留在窄畫幅內。

模型仍採風格化、無品牌的示意幾何。橋式量測機的門架、平台與探針依[量測機原理圖](https://www.mitutoyo.com/webfoo/wp-content/uploads/E11003-Quick-Guide.pdf)配置；手動拖板車的雙叉、負載輪與操控柄依[拖板車結構說明](https://www.toyotaforklift.com/resource-library/blog/toyota-products/anatomy-of-a-hand-pallet-jack)配置。比例與表面細節以本網站觀看距離調整，並非任何實際設備的精確複製。
